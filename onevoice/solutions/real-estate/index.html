What actually goes wrong

Where the calls are going today

  • Buyers call about a sign while you’re standing in someone else’s kitchen
  • A missed call at 8pm is a buyer calling the next agent by 8:05
  • Sign calls arrive with no context about which property they saw
  • Weekend enquiries pile up until Monday, by which point they’re cold
What OneVoice does

What it handles for you

  • A dedicated number per listing, so the agent knows which property they’re calling about
  • Answers questions from your listing detail — price, beds, baths, features, availability
  • Qualifies the buyer: timeline, pre-approval, what they’re actually looking for
  • Books showings against your live Google or Outlook calendar
  • Texts you the caller, the number and a lead score the second the call ends
  • Handles Spanish-speaking buyers on the same number

Questions, answered

Can I have a different number for each listing?
Yes — that’s the point. Each listing gets its own line and its own knowledge, so the agent answers about that specific property instead of asking the caller which house they mean.
What does it actually tell a buyer?
Whatever you put in the listing’s knowledge base: price, bedrooms, bathrooms, square footage, features, showing availability, HOA notes. It works from what you give it and hands off anything outside that.
Does it sync with my calendar?
Two-way with Google Calendar and Microsoft Outlook, so it never books a showing into a slot you’ve already given away.
How much does it cost for a few listings?
Lite is $99/mo for one agent, Basic is $297/mo for up to four, Pro is $497/mo for up to six — plus a per-answered-call rate and a one-time setup fee. Additional agents are $99/mo each.
